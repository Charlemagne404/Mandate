# Mandate vertical alpha implementation report

Mandate now ships an integrated local desktop alpha: choose a country on a global political map, submit a directive, resolve independently planned government responses, advance ongoing projects and strategic conflicts, inspect committed causes, and save, restore or branch a history. The packaged application starts its own services and renderer. It launches without model configuration in explicitly labeled deterministic demo mode.

The orchestration and model transports are implemented, but unrestricted natural-language understanding and real-model geopolitical quality have not been demonstrated. Demo mode uses bounded clause and keyword rules. The alpha's strategic mechanics are intentionally coarse. Those distinctions matter when assessing playability.

## Architecture and canonical state

The existing pure deterministic TypeScript core remains independent of AI, SQLite, Electron and Node APIs. Versioned Zod schemas define finite commands; sequential domain validation and executable invariants precede atomic SQLite commit. Revision/hash checks prevent stale proposals. Provider output has no SQL, shell, filesystem, evaluation or tool capability. Narration follows committed events and cannot create facts.

World/save/scenario version 2 adds canonical initiatives, negotiations and international organizations, richer nation indices and bilateral relations, conflict exhaustion/logistics/settlement state, goal visibility/deadlines/blockers/evidence, and factual event effects. Nation measures are normalized scenario proxies, not actual GDP, soldiers or casualties. Goals remain persistent authored objects; planning consults them, but automatic evidence-based goal completion is unfinished.

The original migration remains intact. `002_alpha.sql` adds canonical entities, expanded fields and transactional turn audits. `003_settlements.sql` adds conflict links for settlement offers and treaties. Validated v1 imports migrate to v2 with neutral defaults. Existing database migration checksums remain unchanged. Model traces commit atomically with state, action, commands, provenance, events, revision and simulation time; a failure rolls back the entire mechanical turn.

Eight new commands expand the vocabulary from 19 to 27: `START_INITIATIVE`, `CANCEL_INITIATIVE`, `OPEN_NEGOTIATION`, `RESPOND_NEGOTIATION`, `CREATE_ORGANIZATION`, `SET_ORGANIZATION_MEMBERSHIP`, `CONFLICT_ACTION`, and `APPLY_DOMESTIC_PRESSURE`. Existing narrow government, leader, goal, claim, treaty and territory commands remain available to debug/editor workflows. There is no generic entity patch command.

## AI workflow, autonomy and memory

Versioned contracts cover PlayerIntent, RelevanceSelection, NationPlan, DiplomaticMove, ResolutionProposal, CriticResult, NarrationInput and HistoricalSummary. Active model roles are formalizer, planner, diplomat, resolver, selective critic and narrator. Relevance and source-linked summarization are deterministic. Advisor is reserved, without a shipped player-facing service.

A turn formalizes source clauses, expands relevance through canonical relationships, builds government-specific context, concurrently joins independent government plans, gathers diplomatic moves, resolves proposals, checks schemas/capabilities/domain rules/consistency/invariants, then commits atomically. One bounded repair is available for failed formalization or resolution. Critical failures abort; a secondary background planner can fail without discarding unrelated valid plans. Cancellation before commit joins pending inference and leaves canonical state untouched. Post-commit narration failure falls back to factual event titles.

Ollama and generic OpenAI-compatible HTTP endpoints support structured generation, health checks, one default model or role overrides, temperature, timeout, retries, cancellation, bounded response size and explicit character budgets (48,000 characters by default). Redirects are rejected. No model weights are bundled. Observable records retain provider/model/role, prompt version, context references, raw application output, parsed output, latency, retries, validation failures and repair attempts. Hidden reasoning is neither requested nor recorded.

The scheduler activates directly affected governments, pending diplomatic recipients, crisis participants and a bounded salience-ranked background selection. Two rotating background slots prevent starvation. Canonical revision/history determine eligibility, preserving branch/replay continuity. Fast/Balanced/Deep change orchestration breadth and critic participation, rather than hardcoding model brands.

Contexts prioritize live entities, visible commitments/conflicts/goals/projects, exact recent facts and source-linked historical summaries. Private internal clauses stay with their issuing government; targeted private diplomatic clauses reach only their intended recipients. Foreign contexts omit treasury/readiness and other internal indices, exposing a limited public proxy projection. Normal inspectors and event effects similarly hide foreign internal indices. Owner debug traces deliberately permit inspection of participating perspectives.

This is an initial public/private boundary. There is no espionage, information acquisition, uncertainty model or secrecy tier system. Summaries are reconstructed factual retrieval hints rather than an indexed long-term semantic memory service. The default global Deep compound-directive regression passes after raising the default budget from 24,000 to 48,000 characters. Explicitly smaller budgets can still abort safely. Context overflow aborts safely; adaptive historical compression and relevance dropping remain incomplete.

## Diplomacy, war, economy and domestic mechanics

Persistent diplomatic threads support consultation, defense, trade, nonaggression, ceasefire and peace. Governments can accept, reject, counter, delay or withdraw; countering swaps the parties and preserves response history. Acceptance must identify the exact offer and match the independent recipient's recorded move. Consultation creates no binding treaty. Binding consent creates the treaty in the same validated command. Expiry and closed-thread rules prevent accepting obsolete offers. Normal response buttons record a player action and enforce the controlled government's authority.

Bilateral ceasefire/peace offers link an active opposing conflict. Ceasefire blocks offensive commands, reduces upkeep/disruption and gradually relieves exhaustion. Ending the ceasefire resumes fighting. Peace ends conflict and supersedes ceasefire, explicitly retaining legal ownership and current military control. Obsolete settlement offers close through factual withdrawals. Direct settlement creation and arbitrary prose territorial terms are rejected. Multilateral bargaining, breach adjudication and negotiated territorial transfer are unfinished.

Strategic conflict actions mobilize, reinforce, defend, attack or de-escalate. Capacity, readiness and logistics determine control changes using deterministic arithmetic. Resource costs, exhaustion and escalation apply to successful and repelled attacks. Combat never changes geometry or legal ownership. There are no tactical units, casualties, route/adjacency logistics or complete alliance obligation mechanics.

Industry, energy, rearmament, reform, diplomacy and aid initiatives have distinct bounded effects, duration, effort, investment, visibility, dependencies and provenance. Unfunded/dependency-blocked projects stall; canceled investment is retained without completion benefits. Fixed 30-day accounting ticks anchored to scenario genesis drive funding, economic convergence, war costs, readiness, unrest, legitimacy and stability. Splitting time advancement does not create extra benefits. Negotiations expire and goal deadlines apply even between ticks. Elections, coups, sanctions, a detailed trade/resource economy and automatic government succession are unfinished.

## Desktop, world, scenarios and UI

Electron main owns a loopback Fastify service, SQLite lifecycle, production React renderer and native dialogs. Renderer sandbox/context isolation remain enabled and Node integration disabled. Fixed preload methods expose only native save import/export, configured folder opening and configuration. Same-origin/host/sender checks protect local services and IPC. External navigation, permissions and unexpected windows are denied. Startup errors preserve the database and appear natively; shutdown cancels inference before closing services and storage.

The application creates local saves, scenarios, exports, logs and service configuration under the Mandate user-data directory. Node SQLite works in the actual Electron runtime; no driver replacement was needed. Packaging bundles production dependencies, migrations, data, renderer and notices. The current artifact is unsigned macOS Arm64 only; signing, notarization, installers and execution on Windows/Linux remain unverified.

The reproducible global baseline uses checksum-pinned Natural Earth 50m administrative countries and populated places: 242 administrative actors/regions, 196 capital points and 327 undirected land-adjacency pairs. Coverage includes territories and disputed polygons; 242 is not a sovereign-state count. The original 177-region registry and permanent IDs are preserved. Original 110m geography and the 13-country northern fixture remain supported; loading a different scenario switches the correct geometry version.

The fictional modern-inspired global scenario starts in 2028 with synthetic neutral governments/leaders/indices, 242 persistent goals, two organizations, two treaties, one South American crisis and one Finnish energy initiative. Geographic facts are separate from invented political content. Structured scenario files pass schema/reference/domain/invariant checks; there is no graphical scenario authoring tool or executable rules language.

The restrained map-dominant UI adds a country inspector, natural-language composer, progress/cancel state, quality and duration controls, event/diplomacy/conflict tabs, threaded negotiations, project progress, map legends and nine ownership/control/diplomatic/organization/conflict/claim/index modes. Country labels use collision filtering; selection focuses the map. Event filters and participant links support browsing history. Foreign internal information is reduced in ordinary views.

Named timelines, autosaves, previous-turn rollback and branches restore actual canonical history with ancestry. Local snapshots retain audited model traces and use compressed storage; undo/autosave retention is 25 each. Plain portable JSON exports retain canonical history but omit supplemental model traces. Full-history snapshots and append-only facts still grow with long saves; this is reliable branching rather than copy-on-write storage.

“Why did this happen?” connects the original action, interpreted intentions, actor activation, contextual goals/commitments, government plans, resolver proposal, deterministic checks, accepted command and factual effects. Advanced expansion reveals context and observable model records. Debug keeps typed command templates and raw inspection, including country/stat/relation/territory/claim/treaty/conflict/government/leader/goal/pressure controls. Observer mode supports 10/25/100 turns in the UI and larger CLI runs. Forced per-government planning and narration rerun controls remain incomplete.

## Local verification and measured limits

- Frozen dependency installation passed. `pnpm verify` passed lint, formatting, strict TypeScript, 217 tests in 13 files, and production builds. It includes all original foundation tests and the 250-turn/500-command deterministic soak.
- Eight Chromium E2E flows passed in 32.3 seconds: compound private diplomacy, causal explanation, save/rollback/branch, global scenario/map/directive, controlled-recipient treaty acceptance, original debug/import flows, and actual production-server termination/restart without external services.
- Both built-in scenarios passed validation. Pinned geographic regeneration reproduced committed outputs byte-for-byte.
- Source desktop smoke verifies actual Electron commit/restart hash, stale-write rejection, foreign-origin rejection, renderer isolation and geography-version round trips. The final packaged application passed the same checks with Electron 44.5.1, Node 24.21.0 and SQLite 3.53.4; renderer sandbox/context isolation were confirmed. The app occupies approximately 348 MiB. Native picker interactions were implemented but not manually exercised. The package was rebuilt and launch-tested again after the final default-budget change.
- The deterministic AI evaluation runs 60 curated interpretation/relevance/visibility cases. Provider trust, repair, cancellation, diplomacy, secrecy, settlement, capability and continuity have separate unit/integration coverage.
- No real model evaluation was executed: the local Ollama and OpenAI-compatible endpoints checked in this environment were unavailable. Fake-provider results do not establish real-model quality or plausible emerging history.

CLI autoplay metrics use an in-memory SQLite store and canonical JSON export; they do not measure durable on-disk commits or complete UI/narration latency. Restart and disk durability are covered separately by integration and desktop tests.

The latest ten-turn global demo measurement produced 58 commands/events, 58 events outside the player, four diplomatic actions, one military-control change, 24 initiated projects, 66 provider-role calls, zero repairs/failures/invariant failures, all 242 goals retained, maximum context 12,781 characters, 724,946 serialized canonical bytes and 161 ms average turn time. Only 23 actors activated during this short sample; it does not prove global long-horizon coverage.

The first northern-fixture 1,000-turn run remained structurally valid with all 13 actors, maximum seven-turn planning gap and zero invariant/provider failures or saturated relations, but generated 2,000 repetitive projects and 1,974 repeated event titles. A subsequent guarded run exposed an unreachable economic-target condition that still repeated industry projects at capped industrial capacity. This was a real policy-quality failure, not a passing simulation-quality result. Benefit/headroom gating was corrected and regression-tested; the final rerun and its measured residual limits follow.

Final guard-fixed 1,000-turn northern-fixture results: 1,564 commands/events, 564 projects (176 rearmament, 169 industry, 11 reform, 104 energy, 104 diplomacy), 1,512 events outside the player, all 13 countries activated with maximum seven-turn planning gap, all 13 goals retained, 3,000 provider-role calls, and zero provider failures, repairs, invariant failures, saturated relations or unresolved negotiations. No active projects remained at the end; the last began in 2033 and the final date was 2107. Canonical JSON was 3,165,522 bytes. Runtime was 383.85 seconds (383.85 ms/turn). Repeated titles fell to 507 from the bad baseline's 1,974, but repetition remains visible. The calm fixture started no new wars/treaties and changed no governments; this proves bounded integrity and policy termination, not rich emergent history.

A separate 100-turn global run produced 598 commands/events, 64 diplomatic actions, one control change, 233 projects and 695 role calls with zero failures/repairs/invariant failures, saturated relations or unresolved offers. It preserved all 242 goals, activated 202 actors, used at most 16,345 context characters, serialized to 3,026,002 bytes and averaged 451.44 ms/turn (45.14 seconds total). Forty actors had not yet activated in this finite sample; the maximum measured gap was the entire 100-turn window. Repeated titles numbered 226. No new wars, treaties or government changes emerged. This confirms executable global autoplay while exposing limited policy/event diversity; a longer global campaign remains necessary.

Reports and portable final states are under `.runtime/evaluation/autoplay-{scenario}-{turns}.json` and `*-save.json`; curated evaluation is `fake-evaluation.json`. These generated local artifacts are ignored by Git. Baseline failure metrics were retained separately for comparison.

Local evidence is macOS/Chromium/current Electron only. Remote CI, other browsers/platforms, signing/notarization and real-model inference have not been run. No existing failure was suppressed or invariant bypassed.

## Licensing, review and next milestone

Natural Earth inputs are public domain; Electron is MIT and packaging/runtime notices are retained. See THIRD_PARTY for source URLs, pinned inputs and license details. Political scenario content and Mandate visuals are original. No proprietary game prompts, code, scenarios or artwork were used. The owner has not selected the project's public distribution license.

Human review should concentrate on `packages/core/src/apply-command.ts` and `packages/core/src/invariants.ts`; schemas and migrations `002_alpha.sql`/`003_settlements.sql`; `packages/ai/src/orchestrator.ts`, `perspective.ts`, `scheduler.ts` and `fake.ts`; `apps/server/src/alpha.ts`/`archive.ts`; desktop main/preload/package tooling; and global scenario generation. These hold authority, consent, disclosure, cancellation, durability and packaging boundaries.

The next substantial cycle is real-model calibration against the existing adversarial/curated harness, followed by evidence-driven persistent goal progress, richer economic commitments and treaty/settlement obligations. It should measure government diversity, grounded continuity and interesting long-horizon outcomes on the global scenario, then improve bounded retrieval/compaction and long-save performance. More provider plumbing alone would not address what remains.
