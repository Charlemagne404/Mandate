Exact direct/transitive dependency versions are locked in pnpm-lock.yaml; their own license notices remain distributed with packages. No copied source snippets, external font, icon pack, proprietary assets, or bundled model weights are used. Typography uses system fonts. The native packaging process copies this document and runtime dependencies with their license files; it retains Electron's upstream notices. This is a dependency/data provenance record, not a grant of a license to the project's original code or a complete distribution/legal certification.

tools/ingest-geography.ts documents pinned upstream revision, checksum, stable-ID assignment and provenance in data/geography/manifest.json. Existing IDs are preserved through a committed registry. Political boundaries are illustrative; not an assertion about disputed sovereignty.

tools/ingest-global-world.ts independently pins the 50m countries and populated-places inputs to the same upstream revision and verifies both SHA-256 checksums before generation. data/geography/global-manifest.json records source URLs, hashes and coverage; global-registry.json retains the original region IDs and adds 50m features. global-metadata.json contains dated source classifications, 196 polities with capital points, and 327 derived land-adjacency pairs. Natural Earth's [terms of use](https://www.naturalearthdata.com/about/terms-of-use/) explicitly place all dataset versions in the public domain (reviewed October 1, 2026).

The 242 generated administrative actors include dependencies, disputed areas, Antarctica and sovereign countries. The scenario deliberately treats them as independently playable fictional administrations. This is not recognition of independence, an assertion of disputed sovereignty, or a contemporary factual political dataset. Leaders, governments, statistics, relationships, organizations, goals, treaties and the starting crisis are authored synthetic values; no proprietary game material is used. Capitals and geographic labels are source metadata, not guarantees of current administrative status.

No runtime/model was installed by this task and no weights are redistributed in the application. Runtime/model digest and test configuration are recorded in `.runtime/evaluation/real-model-metadata.json` and the current development report.
